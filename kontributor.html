Formulir usulan · Tahap awal

Bagikan pengetahuan Anda.

Isi usulan di bawah. Setelah admin mengaktifkan penerima Google Drive, Anda dapat mengirim tanpa akun GitHub ke antrean privat untuk ditelaah. Pengiriman melalui GitHub tetap tersedia.

Jangan tulis alamat lengkap seseorang.
Jangan cantumkan informasi pribadi penutur atau unggah rekaman tanpa izinnya.
Sebelum melanjutkan

Pilih jalur dengan sadar: laporan GitHub dapat dilihat publik; usulan Google Drive (setelah diaktifkan) hanya masuk antrean privat yang dibaca pengelola berizin. Jangan sertakan nomor telepon, alamat lengkap, identitas penutur lain, rekaman sensitif, atau teks berhak cipta tanpa izin.

Pengiriman tanpa akun GitHub belum aktif karena Web app meminta login Google. Admin perlu mengubah akses deployment menjadi Anyone, lalu menguji ulang. Gunakan GitHub atau salin draf sementara.

Bisa berkontribusi apa?

Bukan hanya kosakata.

  • Arti dan contoh yang digunakan sehari-hari
  • Perbedaan ejaan atau pengucapan menurut wilayah
  • Istilah adat, makanan, tumbuhan, dan lingkungan
  • Koreksi kata atau padanan yang keliru
  • Judul, halaman, atau tautan sumber yang bisa diperiksa

Keamanan dan hak penerbitan

Kontribusi adalah usulan, bukan penyuntingan langsung. Usulan Google Drive hanya disimpan dalam antrean privat milik proyek, bukan diterbitkan otomatis. Berkas website dan database hanya dapat diubah pengelola berizin.

Pengiriman tanpa akun GitHub tersedia setelah administrator mengaktifkan penerima Google Drive. Sebelum itu, gunakan GitHub atau salin draf.

Lebih suka formulir GitHub?

Gunakan formulir resmi di repositori, dengan pilihan jenis kontribusi dan kotak bukti terstruktur.

Prinsip penelitian

Bukti sebelum diterbitkan.

Kamus Mandailing memisahkan bentuk sumber, penafsiran makna, padanan yang telah dikurasi, dan kontribusi yang masih perlu ditelaah.

  • Hindari menebak arti atau mengarang kutipan sebagai fakta.
  • Perbedaan dialek dicatat; tidak otomatis dianggap salah.
  • Sumber dan izin dipertahankan agar asal informasi bisa ditelusuri.
Hak komunitas

Kredit dan penghormatan.

Kontributor dapat memakai nama akun GitHub atau menuliskan preferensi kredit pada laporan. Kami tidak menjanjikan pengakuan nama penutur tanpa persetujuan mereka.

  • Admin dapat meminta klarifikasi sebelum menerima usulan.
  • Kontribusi dapat diterima, direvisi, ditunda, atau ditolak dengan alasan.
  • Materi yang memerlukan izin khusus harus melalui jalur privat yang disetujui pengelola, bukan GitHub Issues publik.
Pertanyaan umum

Yang perlu diketahui kontributor.

Apakah usulan langsung muncul di kamus?

Tidak. Usulan masuk antrean telaah. Penambahan ke database dan website publik hanya dilakukan melalui proses editorial dan penerbitan yang disetujui pengelola.

Apakah saya mendapat hak edit GitHub setelah mengirim?

Tidak. Mengirim GitHub Issue tidak memberikan izin menulis atau mengubah kode repositori.

Bolehkah mengirim variasi dari Mandailing Julu, Mandailing Godang, atau diaspora?

Ya. Tuliskan wilayah secara umum dan, bila diketahui, bentuk ucapan serta konteks penggunaannya. Jangan samakan semua variasi tanpa bukti.

Bagaimana jika tidak punya akun GitHub?

Anda tidak memerlukan akun GitHub untuk memakai tombol “Kirim tanpa akun GitHub” setelah admin mengaktifkan kanal Drive. Jika tombol belum aktif, salin draf terlebih dahulu. Tidak perlu membuat akun khusus.

Bisakah mengirim rekaman suara?

Jangan menaruh rekaman orang lain di GitHub Issues tanpa persetujuan yang sah. Sistem penerimaan audio dengan persetujuan penutur dan kontrol akses akan dikembangkan terpisah.
