# Pemindahan proyek Hata — 27 Oktober 2026

Catatan historis pemindahan 27 Oktober 2026. Persiapan alamat utama berikutnya dicatat pada [pemindahan 29 Oktober 2026](migrasi_20261029.md).

Repositori utama: https://github.com/ensiklopedia-mandailing/kamus

GitHub Pages: https://ensiklopedia-mandailing.github.io/kamus/

Pemindahan menggunakan berkas rilis terakhir yang tersedia di lingkungan kerja. Berkas sumber, hasil penelitian, aplikasi HTML mandiri, database JSON/SQLite/TSV, serta paket unduhan dipindahkan bersama. Riwayat commit yang sudah ada di repositori tujuan tetap dipertahankan.

## Data yang dipertahankan

- 10.250 bentuk sumber unik, termasuk 1.404 entri dengan padanan.
- 12.679 lokasi rujukan dan sembilan sumber bentuk.
- 183 pengamatan nama tumbuhan pembanding yang tetap terpisah.
- ID entri dan bentuk, label bahasa, status penelaahan, serta bidang padanan yang belum ditelaah.

Tautan aplikasi dan unduhan dari HTML luring mengarah ke GitHub Pages baru. Tautan berkas di dalam situs tetap relatif agar berfungsi di subdirektori `/kamus/`. Metadata canonical mengacu pada alamat baru.

## Penyimpanan pribadi

Favorit, kemajuan belajar, dan kata pribadi disimpan pada localStorage per origin browser. Origin lama dan baru berbeda, sehingga data pribadi tersebut tidak berpindah otomatis. ID dan nama kunci penyimpanan aplikasi tetap dipertahankan. Database publik tidak memuat data pribadi browser.

## Pemeriksaan

Jalankan `python3 build.py`, `python3 research/validate_release.py`, dan `python3 research/package_release.py`. Paket aplikasi dan paket database memiliki daftar SHA-256. Pengujian integritas memastikan jumlah, padanan kosong, rujukan, dan identitas lama tidak berubah.
